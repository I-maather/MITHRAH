# Maather Trader — تطبيق iOS الأصلي

عميل **مراقبة وتحكّم بالتقليل** لنظام مآثر. يعرض حالة النظام، ويستطيع ثلاثة
إجراءات تُقلّل المخاطرة، ولا يستطيع شيئاً غير ذلك.

A native iOS client (React Native + Expo, TypeScript strict, Expo Router). It is
a **monitoring and risk-reducing control** app — not a trading terminal.

**وثائق أعمق:** `docs/IOS_ARCHITECTURE.md` · `docs/IOS_SECURITY.md` ·
`docs/MOBILE_PRIVACY.md` · `docs/APNS_SETUP.md` · `docs/TESTFLIGHT_RELEASE.md`

## ما يستطيعه هذا التطبيق · What it can do

| | |
|---|---|
| يعرض | حالة النظام، اتصال الوسيط، حالة السوق، الملف المختار والفعّال، المخاطرة المستهلكة والمتبقية، القرار النهائي، النتيجة الحتمية، حالة الاستراتيجية، اكتمال البيانات، الحدث القادم، المركز الحالي، سبب الامتناع، آخر تحديث |
| يطلب | **إيقاف مؤقت** (`pause/request`) |
| يفعّل | **قاطع الطوارئ** (`killswitch/activate`) |
| يلغي | **هذا الجهاز** (`device/revoke`) |

الثلاثة **لا تفتح شيئاً**. أسوأ ما يفعله مهاجم يمسك هذا الهاتف مفتوحاً هو إيقاف
التداول.

## ما لا يستطيعه · What it cannot do

* لا يُنشئ أمراً، ولا يعدّل كمية ولا وقفاً ولا هدفاً.
* لا يفتح مركزاً ولا يغلقه ولا يغيّر رافعة.
* لا يرفع ملف المخاطرة، ولا يقصّر تبريده — التبريد مفروض على الخادم.
* لا يلغي قاطع الطوارئ. الإلغاء إجراء **يزيد** المخاطرة ويحتاج الخادم.
* لا يعيد تفعيل مفتاح وسيط ولا يغيّر تفضيلاته.

## ما لا يملكه · What it never holds

هذه كلها على الخادم (FastAPI) ولا مسار لها إلى الحزمة:

* اعتماد الوسيط: المعرّف، كلمة المرور، مفتاح الواجهة.
* رموز جلسة الوسيط بأي شكل.
* مفاتيح مزوّدي بيانات السوق والأخبار والبيانات الكلية.
* مفتاح توقيع الإشعارات لدى Apple، ومعرّفه، ومعرّف الفريق.
* سرّ توقيع الأوامر، ورابط قاعدة البيانات.

**لا يعرف هذا التطبيق الوسيط أصلاً.** لا يوجد في `mobile/` أي عنوان وسيط: كل
وصول للوسيط يقع في الخادم، والتطبيق يتكلّم مع خادم مآثر فقط.

سلسلة المفاتيح تحمل **ثلاثة أشياء لا رابع لها**: رمز وصول التطبيق، ورمز تجديده،
ومعرّف الجهاز الذي أصدره الخادم. راجعي `src/auth/tokenStore.ts`.

وبيانات الشاشات تعيش في **ذاكرة العملية وحدها**: لا قاعدة بيانات محلية، ولا
ملفات، ولا تخزين غير سلسلة المفاتيح. إغلاق التطبيق يمحوها.

## الأمان · Security model

### Face ID بوابة محلية لا مصادقة خادم

```
Face ID / رمز الجهاز   =  بوابة وصول على هذا الهاتف
رمز الخادم القصير      =  المصادقة الفعلية (١٥ دقيقة، ويُجدَّد بتدوير إجباري)
```

عبور البوابة **لا يمنح صلاحية**: كل طلب يحمل رمز الخادم، والخادم يعيد فحصه في كل
مرة. لو أُلغي الجهاز، تفتح البوابة ثم يعود أول طلب بـ401 فتُقفل الجلسة فوراً.
راجعي `src/auth/biometrics.ts`.

**الاحتياط الموثَّق (fallback):**

1. Face ID أو بصمة الإصبع إن كانت مسجّلة.
2. وإلا **رمز الجهاز** — `disableDeviceFallback: false`.
3. وإن لم يكن للجهاز رمز أصلاً، **لا يُفتح التطبيق**: جهاز بلا رمز لا يحمي
   سلسلة المفاتيح.

### الطبقات الثلاث وحالات الجلسة

سقوط أيّها يُغلق الشاشة: جلسة مسجَّلة على الخادم · بوابة محلية مفتوحة · خمول
تحت الحد.

| الحالة | المعنى |
|---|---|
| `BOOTING` | قراءة سلسلة المفاتيح قبل أي رسم |
| `NO_SESSION` | لا رمز تجديد — يلزم تسجيل الجهاز |
| `LOCKED` | البوابة مغلقة، أو انقضى الخمول |
| `UNLOCKED` | الحالة الوحيدة التي تُرسَم فيها شاشات البيانات |
| `REVOKED` | أُلغي الجهاز — تُمحى الرموز |

### طبقات أخرى

* **قفل تلقائي** بعد خمول (افتراضياً دقيقتان، `EXPO_PUBLIC_AUTO_LOCK_MINUTES`).
* **ستر مبدّل التطبيقات**: طبقة مصمتة تُركَّب عند حالة `inactive` — أي **قبل**
  لقطة النظام لا بعدها. لا يُطفأ هذا الستر من الإعدادات.
* **الروابط العميقة لا تُحلّ قبل المصادقة**: الرابط يُحتجَز، ويُفتح بعد الفتح،
  ووجهته لا بد أن تكون في قائمة بيضاء، ولا يُقبل أي معامل استعلام.
* **TLS مفروض**: `NSAllowsArbitraryLoads: false`. العميل يرفض `http://` لأي
  مضيف ليس حلقة محلية أو شبكة خاصة، **ولا يرسل الرمز أصلاً** في تلك الحالة.
* **حارس الغلاف**: كل استجابة يجب أن تحمل `authorises_execution: false`. أي
  استجابة تدّعي غير ذلك تُرفض ولا تُعرض.
* **لا سجلّات حسّاسة**: لا يُطبع رمز ولا جسم استجابة ولا عنوان. رسائل الخطأ
  عربية ومحايدة.
* **لا تحليلات إطلاقاً**: لا حزمة قياس في `package.json`، ولا نقطة إرسال.

## عقد الخادم · Backend contract

البادئة: `/api/mobile/v1`

**قراءة (GET):** `status` · `intelligence/latest` · `decision/latest` · `risk` ·
`profiles` · `positions/current` · `trades` · `performance` ·
`providers/health` · `notifications` · `audit/recent`

**تعديل (POST) — ثلاثة فقط:** `pause/request` · `killswitch/activate` ·
`device/revoke`

كل استجابة GET:

```json
{
  "route": "status",
  "server_time_utc": "...",
  "device_id": "...",
  "authorises_execution": false,
  "data": { }
}
```

المصادقة: `Authorization: Bearer <access token>` — ١٥ دقيقة. رمز التجديد ٣٠
يوماً ويُدوَّر عند كل استعمال. أي رمز غير صالح أو منتهٍ أو لجهاز مُلغى ⇒ 401.

القائمتان في `src/api/routes.ts` **نسخة طبق الأصل** من `backend/app/mobile/api.py`،
وتُفحَصان حرفاً على الجانبين معاً كي يُكتشف الانحراف أياً كان مصدره.

### مسار التجديد

مجال `v1` يرفض أي POST غير الثلاثة، فالتجديد يقع **خارجه** على
`/api/mobile/session/refresh` (ثابت في `src/api/config.ts`). إن لم يكن هذا
المسار متاحاً بعد على الخادم، **يفشل التطبيق مغلقاً**: تُمحى الرموز ويُطلب
تسجيل الجهاز من جديد، ولا يُستمر برمز منتهٍ.

التجديد **واحد متزامن** مهما تعدّدت الطلبات المتوازية، وبعد 401 تُعاد المحاولة
**مرة واحدة** لا أكثر.

### دورة الجلب في الشاشة

```
useEndpoint(c => c.getX())
   ├─ وضع المعاينة: يعيد fixtures ولا يُرسل طلباً إطلاقاً
   ├─ لا يعمل إلا حين status === 'UNLOCKED'
   ├─ عند الفشل: يحتفظ بآخر بيانات ناجحة ويرفع علم القِدَم — لا يمحوها
   └─ العمر > 90 ثانية ⇒ شريط «قديمة»
```

شاشة فارغة تدفع إلى إعادة الفتح مراراً؛ **شاشة قديمة موسومة بأنها قديمة تقول
الحقيقة.**

## التشغيل · Setup

### المتطلبات

* macOS مع Xcode 15+ (للبناء الأصلي).
* Node 18.18 أو أحدث.
* حساب مطوّر Apple **عند الرغبة في التوزيع** — لا شيء هنا مسجَّل لدى Apple بعد.

### أول مرة

```bash
cd mobile
npm install
cp .env.example .env      # ثم املئي القيم محلياً
```

`.env` مُستثنى من git. لا تضعي فيه أي سرّ — ليس فيه ما يحتاج سرّاً.

| المتغيّر | الافتراضي | ماذا يعني |
|---|---|---|
| `EXPO_PUBLIC_API_BASE_URL` | `http://127.0.0.1:8000` | حلقة محلية عمداً — لا مضيف عام في المصدر |
| `EXPO_PUBLIC_IOS_BUNDLE_ID` | `com.maather.autonomoustrader` | **مبدئي، ولم يُسجَّل لدى Apple** |
| `EXPO_PUBLIC_AUTO_LOCK_MINUTES` | `2` | دقائق الخمول قبل القفل |
| `EXPO_PUBLIC_PREVIEW_DATA` | `0` | `1` يعرض بيانات المعاينة موسومة |

### التطوير

```bash
npm start          # خادم Metro
npm run typecheck  # tsc --noEmit  (strict)
npm run lint       # eslint، ويشمل حراسة لغوية ضد بناء الأوامر
npm test           # jest + @testing-library/react-native
```

في وضع التطوير تظهر بيانات `src/fixtures/` مع شريط **«معاينة / Preview»** على كل
شاشة. لإطفائها اضبطي `EXPO_PUBLIC_PREVIEW_DATA=0` وابني بوضع الإنتاج.

أرقام المعاينة **مصطنعة وواضحة الاصطناع** (قيم مستديرة، أداة واحدة، طابع زمني
مرجعي ثابت) كي لا تُقرأ يوماً على أنها نتيجة حقيقية.

### البناء لـiOS

```bash
npx expo prebuild --platform ios   # يولّد مجلد ios/ (غير مُتتبَّع في git)
npx expo run:ios                   # بناء وتشغيل على محاكٍ أو جهاز
```

الأصول في `assets/` **نائبة مولَّدة** لا فن ولا أصول Apple:

```bash
npm run assets:placeholders        # يعيد توليدها من scripts/
```

استبدليها قبل أي تقديم. لم يُسجَّل شيء لدى Apple: `com.maather.autonomoustrader`
معرّف **مبدئي** يُقرأ من `EXPO_PUBLIC_IOS_BUNDLE_ID`، ويظهر في مكان واحد فقط
(`app.config.ts`) ويُقرأ في التطبيق عبر `src/api/config.ts`.

إجراء التوزيع كاملاً — بما فيه انتهاء البناء بعد ٩٠ يوماً وإجراء تجديده —
في `docs/TESTFLIGHT_RELEASE.md`.

### الوصول من خارج جهاز الخادم

الخادم يربط نفسه بـ**localhost** ولا يُربَط بكل الواجهات بحال. الطريق المقصود
من الهاتف هو **شبكة خاصة مشفّرة بين الجهازين**، وتفصيله في وثيقة الوصول الخاص
تحت `docs/`. **لا شيء منه مثبَّت أو مُعدّ بعد.**

### الاتجاه من اليمين إلى اليسار

التطبيق **عربي أولاً** ولا يتبع لغة النظام. `I18nManager.forceRTL(true)` يكتب علماً
أصلياً يسري في **الإقلاع التالي**، فأول تشغيل بعد تثبيت جديد قد يرسم من اليسار.
لا نخفي ذلك: يظهر شريط يطلب إغلاق التطبيق وفتحه مرة واحدة، ثم يستقرّ الاتجاه.

البوابة. وحين يسقط القفل تُفكَّك شجرة الشاشات فلا يبقى محتوى معروضاً.

## النسق · Design system

نسق أصلي، **لا يحاكي هوية أي وسيط**. القاعدة: **اللون يحمل معنى واحداً فقط،
ولا يُلوَّن رقم للزينة.**

| الدور | الرمز |
|---|---|
| تفاعلي | **أثل** — أخضر مزرقّ هادئ |
| ربح محقق أو حالة سليمة | **نخل** |
| خسارة أو عطل | **رمّان** |
| نقص بيانات أو انتظار | **كثيب** |
| معلومة محايدة | **سماء** |

الوضعان (فاتح/داكن) يتبعان النظام، وأسماء الألوان تصف **الدور** لا الصبغة فلا
يتغيّر شيء في مواضع الاستعمال. و**تقليل الحركة** من إعدادات iOS مُحترَم:
`duration()` تعيد صفراً عند تفعيله.

## حدود هذه النسخة · Known limits

* **لا تسجيل جهاز في التطبيق بعد.** الشاشة تشرح أن التسجيل يتم من لوحة الخادم
  برمز QR صالح دقيقتين ولمرة واحدة؛ استقبال ذلك الرمز في التطبيق يأتي مع تفعيل
  التسجيل على الخادم.
* **`/api/mobile/session/refresh` غير مبنيّ بعد على الخادم.** التطبيق يفشل
  مغلقاً حتى يُبنى.
* **لا إشعارات مُسجَّلة بعد**: شاشة الإشعارات تقرأ ما يرسله الخادم؛ تسجيل رمز
  APNs يأتي مع إعداد الاعتمادات على الخادم، ولا يمرّ منها شيء بالجهاز.
  ولا يوجد تنفيذ APNs حقيقي في المستودع أصلاً — مُقلِّد فقط
  (`docs/APNS_SETUP.md`).
* **الإشعار استشاري ولا تعتمد عليه أي سلامة**: وقف الخسارة وجني الأرباح لدى
  الوسيط لا في الهاتف.
* **الأصول نائبة**، ولا شيء مسجَّل لدى Apple.
* `npm install` و`npx expo prebuild` و`expo run:ios` تحتاج جهاز المالكة (macOS).
