# Maather Autonomous Trader — متداول مآثر الذاتي

نظام تداول ذاتي شخصي لمستخدمة واحدة، واجهة عربية RTL بتوقيت الرياض،
مصمَّم للاتصال بـInteractive Brokers، مع دستور مخاطر مفروض بالكود لا بالتعليمات.

**استخدام شخصي فقط. ليس منتجاً ولا خدمة استشارات مالية.**

---

## ⚠️ اقرئي هذا أولاً

| البند | الحالة |
|---|---|
| التداول الحقيقي | 🔒 **مقفل** — `LIVE_TRADING=false` |
| الربط بـIBKR | ⛔ **غير مكتمل** — المحوّلات هياكل ترفع خطأً صريحاً |
| الاستراتيجية | ⚠️ **RESEARCH** وليست معتمدة — لا Backtest بعد |
| رأس المال | **150.00 USD** — وضع المخاطرة الافتراضي `VALIDATION` |
| جدوى التداول الآلي عند 150 دولاراً | ❌ **غير كافٍ** — الحد الأدنى ~255 دولاراً في `CONSERVATIVE_LIVE` |
| جدوى صفقة Commissioning (5–10 دولارات) | ✅ **ممكنة** ضمن حد 0.75 دولار |
| الاختبارات | ✅ 200 اختبار أخضر |

النظام **يعمل** ويتخذ قرارات صحيحة قابلة للتفسير — والقرار الصحيح للتداول الآلي
عند 150 دولاراً هو `NO_TRADE`. هذا سلوك سليم وليس عطلاً.

---

## التشغيل

```bash
make install      # تثبيت الاعتماديات (باك-إند + واجهة)
make test         # كل الاختبارات
make run          # تشغيل النظام كاملاً محلياً
```

بعدها: الواجهة على <http://localhost:3000> و API على <http://127.0.0.1:8000/docs>.

أوامر مساعدة:

```bash
make feasibility    # إعادة توليد تقرير جدوى رأس المال من نموذج التكلفة
make verify-audit   # فحص سلامة سلسلة سجل التدقيق
```

## ما لا يعد به هذا النظام

- لا نسبة ربح، ولا وعد بأن 150 دولاراً ستنمو.
- الذكاء الاصطناعي هنا **لا يتخذ أي قرار تداول** — يشرح ويلخّص فقط.
- اجتياز الاختبارات الهندسية لا يعني ربحية.
