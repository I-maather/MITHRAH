# Maather Autonomous Trader — متداول مآثر الذاتي

نظام تداول ذاتي شخصي لمستخدمة واحدة، واجهة عربية RTL بتوقيت الرياض،
**محايد تجاه الوسطاء**: الوسيط التشغيلي الأول **Capital.com** (CFD على EUR/USD)،
و**IBKR محفوظ كمرحلة مستقبلية معطّلة** للأسهم العالمية والسوق السعودي.
دستور المخاطر مفروض بالكود لا بالتعليمات.

**استخدام شخصي فقط. ليس منتجاً ولا خدمة استشارات مالية.**

## لماذا تغيّر الوسيط

نتيجة IBKR («الحد الأدنى ~255–380 دولاراً») مصدرها **الحد الأدنى للعمولة 0.35 دولار
لكل رجل** — وهي بنية تسعير أسهم. Capital.com لا تفرض عمولة على فوركس CFD،
والتكلفة سبريد فقط. لذلك:

**النتيجة القديمة لا تُنقل ولا يُعاد استعمالها.** أُعيد الحساب من الصفر لبنية
تكلفة Capital.com، ويوجد اختبار (`test_ibkr_255_380_conclusion_is_not_reused_for_capital_com`)
يفشل إن تسرّب الرقم القديم إلى مسار CFD.

التفاصيل: `docs/CAPITAL_COM_MIGRATION_AUDIT.md` · `docs/IBKR_FUTURE_PHASE.md`.

## ثلاث قيم لا تُخلط أبداً

| القيمة | مثال (EUR/USD كمية 100 @ 1.08546) |
|---|---|
| قيمة التعرّض (Notional) | 108.55 دولار |
| الهامش المحجوز (Margin) — **ليس خسارة** | 1.09 دولار |
| **الخسارة النقدية عند الوقف (All-in)** | 0.27 – 0.77 دولار |

الحد المقارَن بالدستور هو **الثالثة فقط**.
لهذا لا يُوصف أمر CFD بأنه «أمر بـ5–10 دولارات» — ذلك كان منطق أسهم.

## التشغيل

```bash
make install      # تثبيت الاعتماديات (باك-إند + واجهة)
make test         # 446 اختباراً
make run          # تشغيل النظام كاملاً محلياً
```

الواجهة على <http://localhost:3000> و API على <http://127.0.0.1:8000/docs>.

```bash
make verify-audit    # فحص سلامة سلسلة سجل التدقيق
make feasibility     # إعادة توليد تقرير جدوى رأس المال

cd backend
alembic upgrade head                                  # 24 جدولاً
python3 -m app.cli constitution                       # طباعة الحدود السارية
python3 -m app.cli secrets-status                     # وجود الاعتمادات، بلا قيم
python3 -m app.cli capital-discover --environment demo # اكتشاف قراءة فقط
```

`--environment live` **مرفوض عند تحليل الوسائط نفسه**.

## الاعتمادات — لن تُطلب في المحادثة أبداً

```bash
./scripts/configure_capital_credentials.sh
```

سكربت محلي لا يتصل بالإنترنت، الكتابة مخفية، يطلب كل قيمة مرتين،
يفضّل macOS Keychain ويستخدم ملفاً بصلاحية `600` كبديل.
لا يقبل سرّاً في سطر الأوامر، ولا يدخل سجل الصدفة، ولا يطبع أي قيمة.

الدليل الكامل: `docs/CAPITAL_COM_CREDENTIAL_SETUP.md`.

## ما لا يعد به هذا النظام

- لا نسبة ربح، ولا وعد بأن 150 دولاراً ستنمو.
- الذكاء الاصطناعي هنا **لا يتخذ أي قرار تداول** — يشرح ويلخّص فقط.
- اجتياز الاختبارات الهندسية لا يعني ربحية.
- الوقف العادي **لا يضمن** الخسارة المقدَّرة عند الفجوة السعرية.
- لا توجد بيانات EUR/USD تاريخية حقيقية في المستودع، ولا نتيجة Backtest واحدة.
  **لا تُلفَّق بيانات ولا نتائج.**
