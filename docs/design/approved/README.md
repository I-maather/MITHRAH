### ما يحويه النموذج

سبع شاشات كاملة، لا لقطة بطل واحدة:

1. **اليوم** — الحالة الآنية: ما يفعله النظام الآن، وما آخر ما فعله.
2. **المحفظة** — التعرّض والمخاطرة والحدود، بأرقامها لا بشعورها.
3. **السجل** — الصفقات المكتملة والمطابَقة، بنتائجها المحققة.
4. **النظام** — الصحة التشغيلية: الوسيط، الدورة، النسخة، البوابات.
5. **مركز مفتوح** — تفصيل مركز واحد: الدخول، الإبطال، الحماية، الإدارة.
6. **صفقة مغلقة** — التفصيل بعد الإغلاق: النتيجة، الرسوم، جودة القرار والتنفيذ.
7. **حالات النظام الأربع** — يعمل · متوقّف · يطابق · معطوب.

- لا يُستخدم تصميم «القِرْطاس» ولا «الأُفُق». الملفان
