# Capital.com Migration Audit — تدقيق الهجرة

**التاريخ:** 2026-08-28 · **من:** 0.1.0 (IBKR) · **إلى:** 0.2.0 (Capital.com أولاً)
**Baseline:** `f985249` · وسم محفوظ: `ibkr-baseline-v0.1.0` · **200 اختبار ناجح قبل أي تغيير**

القرار: **الوسيط التشغيلي الأول صار Capital.com** لصفقات EUR/USD CFD صغيرة جداً.
IBKR يبقى محوّلاً معطّلاً لمرحلة مستقبلية (أسهم عالمية، أسهم كسرية، السوق السعودي، رأس مال أكبر).
النظام يبقى **محايداً تجاه الوسيط**: لا مكوّن مخاطرة أو تنفيذ يعرف اسم وسيط بعينه.

## 1. التصنيف الكامل

### أ. محايد تجاه الوسيط وأُعيد استعماله كما هو ✅

| المكوّن | لماذا صلح كما هو |
|---|---|
| `BrokerAdapter` (18 ميثود) | العقد صيغ حول مفاهيم عامة (حساب، أداة، أمر، تأكيد)، فاستوعب CFD دون تغيير توقيع واحد. هذا هو العائد الحقيقي لقرار ADR-001. |
| `MockBrokerAdapter` | يحاكي الرفض والمهلة والتعبئة الجزئية — كلها حالات تخص أي وسيط. |
| `Kill Switch` (22 مُطلِقاً) | كل مُطلِق مُعرَّف بالظاهرة لا بالوسيط: بيانات قديمة، انقطاع، اختلاف مطابقة، أمر مكرر. |
| `Audit Log` مسلسل بالـhash | لا يعرف الوسطاء أصلاً. |
| `execution/orders.py` — idempotency، معاينة، تأكيد، مطابقة | الدورة نفسها تنطبق حرفياً على `dealReference` بدل `orderId`. |
| `marketdata/service.py` | بوابة الحداثة والسبريد والمصدر — مفاهيم عامة. |
| `clock.py` | UTC داخلياً وعرض الرياض. |
| `money.py` | Decimal في كل مكان. |
| بوابات Risk Engine (الخسائر، المراكز، الأخبار، الموافقة) | استُخرجت إلى `_run_gates()` وتُستعمل الآن من المسارين معاً. |

| `risk/sizing.py` (حلّ عكسي للكمية) | باقٍ. منطق «كم سهماً كسرياً أشتري» لا معنى له في CFD بكمية دنيا. |

### ج. عُدّل ليستوعب Capital.com 🔧

| المكوّن | التعديل | لماذا |
|---|---|---|
| `contracts.py` | أُضيفت `Broker`, `StopKind`, `ExecutionUncertainty`، وحقول CFD اختيارية على `InstrumentDetails` (epic, margin_factor, min_stop_distance, guaranteed_stop_available, pip_size…) | إضافة فقط بقيم افتراضية — لم يسقط أي اختبار قائم. |
| `risk/constitution.py` | الإصدار 0.2.0: وضع `LOCKED_REVIEW`، قيود كمية **حسب الوسيط**، قوائم أدوات **حسب الوسيط**، حد تشغيلي 6.50 مع احتياطي 1.00، سقف 1% من حقوق الملكية الحالية | حدود 5–10 دولارات كانت منطق أسهم؛ في CFD القيد هو الكمية الدنيا للوسيط. |
| `risk/engine.py` | استُخرجت البوابات إلى `_run_gates()`، وأُضيف `evaluate_cfd()` | نفس القواعد لكلا الوسيطين، ومسار حجم مختلف. |
| `db/models.py` | 23 جدولاً: أُضيفت أعمدة الوسيط والبيئة والحساب المقنّع واقتصاديات CFD ويقين التنفيذ، وجدولا `execution_attempts` و`system_state` | ما يمنع إعادة الإرسال الأعمى ويحفظ Kill Switch عبر إعادة التشغيل. |
| `main.py` | `/api/broker`، `/api/cfd-preview`، إيقاف/رفع محلي | عرض التعرّض والهامش والخسارة **منفصلة**. |
| الواجهة | صفحة «الوسيط»، شارة DEMO دائمة، لوحة الإيقاف المحلي | مطلب صريح. |
| `.env.example` | صار للإعدادات غير السرّية فقط + `RISK_MODE` + `CAPITAL_ENVIRONMENT` | الأسرار لا تُسنَد في ملف متتبَّع. |

### هـ. غير آمن أو متناقض أو ملغى ⛔

| البند | الحكم |
|---|---|
| **«الحد الأدنى 255–380 دولاراً»** | **ملغى لـCapital.com.** كان مشتقاً من الحد الأدنى لعمولة IBKR (0.35 دولار للساق). Capital.com لا يفرض عمولة على فوركس CFD بل يتقاضى عبر السبريد. يبقى صحيحاً **لـIBKR وحده**. مُثبت باختبار: `test_ibkr_255_380_conclusion_is_not_reused_for_capital_com`. |
| **«صفقة بـ5–10 دولارات»** كوصف لأمر CFD | **ملغى.** في CFD، 5–10 دولارات قد تعني الهامش أو الخسارة أو لا شيء. الوصف الصحيح: كمية 100 وحدة، تعرّض ~108.55 دولار، هامش ~1.09 دولار، خسارة قصوى 0.27–0.77 دولار حسب مسافة الوقف. |
| **«خسارتان متتاليتان ⇒ توقف حتى الجلسة التالية»** (0.1.0) | **استُبدل** بـ`LOCKED_REVIEW` بلا استئناف تلقائي غداً. الاستئناف التلقائي هو ما يجعل الخسارة الثالثة ممكنة أصلاً. |
| **`TradingPermissions.violates_v1_policy()` على حساب Capital.com** | متناقض ظاهرياً: حساب CFD هو Margin بالتعريف فيعترض. **الحل:** المحوّل يُبلغ الحقيقة (`MARGIN`) ولا يكذب، وسياسة CFD منفصلة في الدستور (`CFD_*`). لم تُخفَّف سياسة الأسهم. |
| **افتراضات الموقع العام** (أقل كمية 100، هامش 1%، عمولة 0%) | **لا تُثبَّت كقيم حساب.** مُعلَّمة `PROVISIONAL_PUBLIC_SITE` وكل حساب مبني عليها يخرج موسوماً «مبدئي». |
| **اعتبار استجابة POST ناجحة دليلاً على تنفيذ** | مرفوض بنيوياً: الدليل الوحيد `GET /confirms/{dealReference}` بحالة `ACCEPTED`. |
| مراجع «مختبر الأبحاث السابق» | لم يُنسخ منها كود. `docs/LEGACY_LAB_AUDIT.md` محفوظ كوثيقة تاريخية. |

## 2. تغييرات مقصودة في اختبارات قائمة

لم يُحذف أي اختبار ولم تُخفَّض التغطية. ثلاثة اختبارات عُدّلت لأن الدستور **تغيّر عمداً**:

| الاختبار | قبل | بعد | السبب |
|---|---|---|---|
| `test_validation_two_losses_stop_until_next_session` | «حتى الجلسة التالية» | `test_two_consecutive_losses_move_to_locked_review_not_tomorrow` | الدستور 0.2.0 يمنع الاستئناف التلقائي. |
| `test_commissioning_mode_constraints` | 5–10 دولارات لكل الوسطاء | قيد حسب الوسيط + اختبار جديد `test_ibkr_commissioning_notional_bounds_are_broker_scoped` | القيد الدولاري خاص بأسهم IBKR. |
| `test_all_three_modes_are_published` | 3 أوضاع | `test_all_four_modes_are_published` | أُضيف `LOCKED_REVIEW`. |

العدد النهائي: **200 → 446 اختباراً**، كلها ناجحة.

## 3. لماذا لا يجوز نقل استنتاج IBKR

| البند | IBKR (أسهم) | Capital.com (CFD فوركس) |
|---|---|---|
| العمولة | 0.35 دولار للساق (Tiered)، سقف 1% من القيمة | صفر عمولة معلنة على الفوركس |
| مصدر التكلفة | عمولة + رسوم تنظيمية + سبريد | **السبريد** + تبييت + (اختياري) رسوم وقف مضمون |
| أصغر صفقة | سهم كسري بقيمة دولارية | **كمية دنيا 100 وحدة** (مبدئي) |
| التعرّض مقابل النقد | التعرّض = النقد المدفوع | التعرّض ~100× الهامش المحجوز |
| أثر ذلك على 150 دولاراً | العمولة وحدها (0.70) تتجاوز حد 0.50 | الاحتكاك ~0.02 دولار لصفقة كاملة |

**النتيجة العددية الجديدة** (مبدئية حتى اكتشاف Demo): كمية 100 على EUR/USD تعطي
خسارة قصوى **0.27 دولار** عند 25 نقطة و**0.52** عند 50 و**0.77** عند 75.
أي أن **150 دولاراً تكفي تقنياً** لصفقة Capital.com ضمن حدود الدستور — وهذا عكس نتيجة IBKR تماماً.

⚠️ **الكفاية التقنية ليست ربحية.** حركة التعادل ~2 نقطة، وهي منخفضة، لكن ذلك لا يقول
شيئاً عن أفضلية الاستراتيجية. الاعتماد يمر ببوابات `docs/STRATEGY_VALIDATION_GATES.md`.

## 4. سياسة الحساب: أسهم مقابل CFD

سياسة V1 للأسهم (Cash · Retail · لا Margin · لا Short · لا مشتقات) كُتبت لحساب IBKR
وتبقى سارية هناك. حساب Capital.com هو CFD برافعة بالتعريف، ولا يمكن جعله Cash.

**ما لم يُخفَّف:** الحد الدولاري للخسارة. الرافعة مسموحة كآلية، لكن أي صفقة
تُترجم إلى خسارة تتجاوز الحد تُرفض. ثوابت `CFD_ALLOW_SHORT=False`،
`CFD_ALLOW_HEDGING=False`، `CFD_REQUIRE_BROKER_STOP=True`،
`CFD_REQUIRE_BROKER_TAKE_PROFIT=True` تُبقي النطاق ضيقاً.
