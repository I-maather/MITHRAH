# IBKR Setup — إعداد حساب Interactive Brokers

> **حدود واضحة:** كل ما في هذا الملف تفعلينه **أنتِ**. النظام لا يفعل أياً منه.

## ما لن يفعله النظام نيابةً عنكِ — أبداً

- ❌ قبول أي عقد أو إقرار قانوني.
- ❌ رفع هويتك أو مستنداتك.
- ❌ إدخال أو حفظ كلمة مرور أو رمز 2FA.
- ❌ تمويل الحساب أو تحويل أموال.
- ❌ طلب Margin أو تصنيف Professional.
- ❌ تفعيل Options أو Futures أو Forex أو Short Selling.
- ❌ إنشاء API credentials.
- ❌ تشغيل `LIVE_TRADING` أو إرسال أول أمر حقيقي.

عند أي خطوة من هذه، يتوقف النظام ويعرض عليكِ ما هو مطلوب وينتظر.

---

## 1. قبل فتح الحساب

اقرئي `docs/CAPITAL_FEASIBILITY.md`. الخلاصة: عند 100 دولار سيرفض النظام التداول دائماً
بشكل صحيح. فتح الحساب ما زال مفيداً (لبيانات Paper وفحص القدرات الفعلية)،
لكن **لا تُموّليه بمبلغ إضافي قبل قرار واعٍ**.

## 2. فتح الحساب

1. من `interactivebrokers.com` → Open Account، دولة الإقامة: **السعودية**.
2. اختيارات إلزامية:
   - نوع الحساب: **Individual**
   - طريقة الحساب: **Cash** (وليس Margin)
   - التصنيف: **Retail** (وليس Professional)
   - الصلاحيات: **US Stocks/ETFs فقط**
3. **لا** تفعّلي: Options · Futures · Forex · Crypto · Short Selling · Margin.
4. سجّلي في الجدول أدناه أي كيان IBKR ظهر لكِ (يحسم `OPEN-IBKR-03`).

## 4. حساب Paper

فعّلي حساب Paper المرافق. كل الاختبار الهندسي يجري عليه أولاً.

## 5. IB Gateway

1. حمّلي **IB Gateway** (وليس TWS) من موقع IBKR.
2. شغّليه على جهازك وسجّلي الدخول بنفسك — النظام لا يلمس بيانات الدخول.
3. فعّلي: `Configuration → API → Enable ActiveX and Socket Clients`.
4. أضيفي `127.0.0.1` إلى Trusted IPs.
5. سجّلي المنفذ الظاهر لديك (Paper و Live يختلفان) في `.env`:

```
BROKER_MODE=IBKR_PAPER
IBKR_HOST=127.0.0.1
IBKR_PORT=<المنفذ الظاهر في IB Gateway>
IBKR_CLIENT_ID=17
IBKR_ACCOUNT_ID=<رقم حساب Paper>
```

**IB Gateway يعمل على جهازك مباشرة، لا داخل Docker** — السبب في `docs/adr/001`.

## 6. الأسرار

- `.env` مستثنى في `.gitignore`. لا تضعي فيه شيئاً تريدين رفعه.
- لا تشاركي أبداً كلمة المرور أو رمز 2FA مع أي نظام — بما فيه هذا النظام.
- تخزين الأسرار في macOS Keychain **غير منفَّذ بعد** (مذكور في القيود المعروفة).
