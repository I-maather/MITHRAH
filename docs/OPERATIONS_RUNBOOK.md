# Operations Runbook — دليل التشغيل

## 1. التشغيل اليومي

```bash
make run            # الباك-إند + الواجهة
make verify-audit   # فحص سلامة سلسلة سجل التدقيق
```

تحققي قبل أي جلسة:
1. صفحة **صحة النظام** — كل المكوّنات خضراء.
2. صفحة **المخاطر** — Kill Switch غير مفعّل، والحدود كما تتوقعين.
3. صفحة **الإعدادات** — الوضع `PAPER/MOCK` ما لم تكوني فعّلتِ Live عمداً.
4. **تأكيد تقويم الأخبار لليوم.** بدون تأكيد يدوي، النظام يرفض التداول (وهذا مقصود).

## 2. الأوامر

| الأمر | ماذا يفعل |
|---|---|
| `make install` | تثبيت اعتماديات الباك-إند والواجهة |
| `make test` | كل اختبارات pytest |
| `make run-api` | الباك-إند فقط على 8000 |
| `make run-ui` | الواجهة فقط على 3000 |
| `make run` | الاثنان معاً |
| `make feasibility` | إعادة توليد `docs/CAPITAL_FEASIBILITY.md` |
| `make verify-audit` | التحقق من سلسلة hash |
| `make backup` | نسخة احتياطية مؤرخة من قاعدة البيانات |

## 3. النسخ الاحتياطي والاستعادة

```bash
make backup                          # ينشئ backups/maather-YYYYMMDD-HHMMSS.db
cp backups/<الملف> data/maather.db   # الاستعادة
make verify-audit                    # إلزامي بعد أي استعادة
```

⚠️ **دورة النسخ/الاستعادة لم تُجرَّب فعلياً بعد** — وهي بند إلزامي في قائمة تفعيل Live.

## 4. Kill Switch

**التفعيل:** صفحة المخاطر ← «إيقاف التداول فوراً» ← سبب مكتوب ← عبارة «أوقف التداول الآن».

**إعادة التفعيل** (لا تحدث تلقائياً أبداً):
1. اقرئي سبب التفعيل في صفحة المخاطر.
2. راجعي سجل التدقيق حول وقت التفعيل.
3. عالجي السبب الجذري.
4. صفحة المخاطر ← «إعادة التفعيل بعد المراجعة» ← الاسم + سبب ≥10 أحرف
   + العبارة «أعد تفعيل النظام بعد المراجعة» + تأكيد المراجعة.

## 5. الصيانة الدورية

| الوتيرة | المهمة |
|---|---|
| يومياً | فحص صحة النظام · تأكيد تقويم الأخبار · مراجعة قرار اليوم |
| أسبوعياً | `make verify-audit` · مراجعة قرارات NO_TRADE وأسبابها · نسخة احتياطية |
| شهرياً | مراجعة فاتورة بيانات السوق · التحقق من عدم تغيّر صلاحيات الحساب |
| سنوياً | **تحديث عطلات السوق** في `clock.py` · مراجعة عمولات IBKR وتحديث `costs.py` و`DATA_SOURCES.md` |

## 6. تغيير رأس المال المرجعي

الإيداع أو السحب يغيّر Baseline، وهذا يعيد حساب **كل** الحدود:
1. أوقفي النظام.
2. حدّثي `BASELINE_EQUITY_USD` في `.env`.
3. سجّلي الموافقة في جدول `approvals` مع السبب.
4. أعيدي التشغيل وتحققي من صفحة المخاطر.

تغيّر Baseline دون هذه الخطوات يُفعّل `BASELINE_CHANGED_WITHOUT_APPROVAL`.
