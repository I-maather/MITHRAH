# iOS Architecture — بنية تطبيق مآثر

**الكود:** `mobile/` · **العقد الخلفي:** `backend/app/mobile/api.py`

عميل iOS أصلي للمراقبة والتحكّم **بالتقليل**. هذه الوثيقة تصف بنيته؛ نموذجه
الأمني في `docs/IOS_SECURITY.md`.

---

## 1. الطبقة التقنية

| البند | القيمة |
|---|---|
| الإطار | React Native `0.74.5` · Expo `51` |
| اللغة | TypeScript **strict**، و`eslint --max-warnings 0` |
| التوجيه | Expo Router `3.5` مع `typedRoutes` |
| المنصّة | **iOS وحدها** — `platforms: ['ios']`، و`supportsTablet: false` |
| التخزين | `expo-secure-store` (سلسلة مفاتيح iOS) — **لا قاعدة بيانات محلية** |
| البصمة الحيوية | `expo-local-authentication` |
| الاختبارات | `jest-expo` + `@testing-library/react-native` — ثلاثة عشر ملفاً |
| التحليلات | ⛔ **لا شيء** — لا حزمة قياس واحدة، ويوجد اختبار يفحص `package.json` |

**لا مكتبة رسوم بيانية ولا شبكات ولا حالة عامة.** `fetch` المدمج وحده، وحالة
React المحلية وحدها.

## 2. المصدر الواحد للإعداد

`app.config.ts` هو المكان **الوحيد** الذي يُعلَن فيه معرّف الحزمة وعنوان
الخادم، ويُقرآن في التطبيق عبر `expo-constants` من `src/api/config.ts` — ولا
يُكرَّران في أي ملف آخر.

| المتغيّر | الافتراضي | ملاحظة |
|---|---|---|
| `EXPO_PUBLIC_API_BASE_URL` | `http://127.0.0.1:8000` | **حلقة محلية عمداً** — لا مضيف عام في المصدر، ويوجد اختبار يمنع ذلك |
| `EXPO_PUBLIC_IOS_BUNDLE_ID` | `com.maather.autonomoustrader` | **مبدئي، ولم يُسجَّل لدى Apple** |
| `EXPO_PUBLIC_AUTO_LOCK_MINUTES` | `2` | دقائق الخمول قبل القفل |
| `EXPO_PUBLIC_PREVIEW_DATA` | `0` | رفعه يعرض بيانات المعاينة موسومة |

و`extra.authorisesExecution = false` ثابت يُختبَر، ويقابله حارس في العميل يرفض
أي استجابة تدّعي غير ذلك.

## 4. التوجيه — حارس واحد لا حرّاس متفرّقون

```
app/_layout.tsx        الجذر: applyRtl() قبل أي رسم · ThemeProvider ·
                       SessionProvider · احتجاز الروابط العميقة · PrivacyVeil
   └─ app/index.tsx    البوابة المحلية — الشاشة الوحيدة خارج الحارس
   └─ app/(app)/_layout.tsx   الحارس: BOOTING ⇒ انتظار، وأي حالة غير
                              UNLOCKED ⇒ Redirect إلى «/»
        └─ ثلاث عشرة شاشة بيانات
```

**لا شاشة بيانات واحدة خارج الحارس.** ولذلك لا يوجد مسار — لا رابط عميق ولا
إشعار ولا استئناف من الخلفية — يعرض رقماً قبل فتح البوابة. وحين يسقط القفل
تُفكَّك شجرة الشاشات فلا يبقى محتوى معروضاً في الذاكرة.

### الروابط العميقة

المخطط `maather://`. القائمة البيضاء **صريحة** بثلاث عشرة وجهة، و**أي معامل
استعلام يُسقط الرابط كاملاً**: معامل واحد يعني محاولة تمرير حالة من الخارج،
وهذا التطبيق لا يقبل حالة من الخارج. ولا يوجد رابط يفتح **إجراءً** — الروابط
تفتح شاشات، والطوارئ شاشة لا فعل.

## 5. تدفّق البيانات

```
شاشة  ──►  useEndpoint(c => c.getX())
             │  (وضع المعاينة: يعيد fixtures ولا يُرسل طلباً إطلاقاً)
             ▼
        MobileApiClient
             │  verifyBaseUrl  ⇒ فشل ⇒ UNTRUSTED_ENDPOINT قبل أي إرسال
             │  Bearer <access>  +  مهلة 12 ثانية
             ▼
        /api/mobile/v1/<route>
             │  401 ⇒ تجديد واحد متزامن ثم إعادة واحدة، وإلا onSessionLost
             │  الغلاف يُفحَص: route · server_time_utc · device_id ·
             │  authorises_execution · data
             │  authorises_execution ≠ false ⇒ رفض ولا عرض
             ▼
        { data, envelope, stale, fetchedAt, error, refresh }
```

| السلوك | القاعدة |
|---|---|
| عند الفشل | **يُحتفَظ بآخر بيانات ناجحة** ويُرفع علم القِدَم — لا تُمحى |
| عتبة القِدَم | `STALE_AFTER_MS = 90_000` — رقم صغير عمداً: قيمة مخاطرة عمرها دقيقتان تبدو حالية وقد لا تكون |
| الجلب | عند التركيب وعند `refresh()` — **لا استطلاع دوري** |
| التمكين | فقط حين `status === 'UNLOCKED'` |

شاشة فارغة تدفع المالكة إلى إعادة الفتح مراراً؛ **شاشة قديمة موسومة بأنها قديمة
تقول الحقيقة.**

## 6. نسق التصميم

`src/theme/` — رموز أصلية، **لا تحاكي هوية أي وسيط**.

| الطبقة | المحتوى |
|---|---|
| `tokens.ts` | لوحة (حبر · ورق · ليل · ضوء)، ولون مميّز **أثل** (أخضر مزرقّ)، وثلاثة دلالية: **نخل** إيجابي · **رمّان** سلبي · **كثيب** تنبيه · **سماء** معلومة · سلّم مسافات 4pt · أنصاف أقطار · طباعة · حركة |
| `colors.ts` | أسماء تصف **الدور** لا الصبغة (`surface`، `textSecondary`، `privacyVeil`…) فالتبديل بين الوضعين لا يمسّ مواضع الاستعمال |
| `ThemeProvider.tsx` | الوضعان تلقائياً من النظام · احترام **تقليل الحركة** من إعدادات iOS · `duration()` تعيد صفراً عند تفعيله |

**القاعدة: اللون يحمل معنى واحداً فقط، ولا يُلوَّن رقم للزينة.**

الاتجاه عربي أولاً ولا يتبع لغة النظام: `I18nManager.forceRTL(true)` تُستدعى في
جذر الشجرة **قبل أي رسم**، لكنها علم أصلي يسري في الإقلاع التالي — فيظهر شريط
صريح يطلب إغلاق التطبيق وفتحه مرة واحدة بدل إخفاء السلوك.

## 8. المعاينة — بوابة واحدة لا مسار خفيّ

`src/fixtures/` بيانات تطوير **ليست حالة النظام**. البوابة الوحيدة
`previewOr()`، وخارج التطوير أو مع إطفاء العلم تعيد `null` فتذهب الشاشة إلى
الخادم.

الأرقام مصطنعة **وواضحة الاصطناع**: قيم مستديرة، أداة واحدة، وطابع زمني مرجعي
ثابت (`2026-01-15T13:40:00+00:00`) كي لا تبدو «حيّة» ولا تُقرأ يوماً نتيجةً
حقيقية. وكل شاشة تعرض شيئاً منها تعرض فوقه شريط **«معاينة / Preview»**، ولا
مسار يجعل هذه القيم تظهر بلا وسم.

في وضع المعاينة **لا يُرسَل طلب شبكة إطلاقاً**.

---

## 9. حدود البنية

- **لا نقطة نهاية تداول** — لا في العميل ولا في الخادم.
- التطبيق **لا يعرف الوسيط أصلاً**: لا عنوان وسيط في `mobile/`، ويوجد اختبار
  يفحص الشجرة كلها.
- `/api/mobile/session/refresh` **غير مبنيّ بعد** على الخادم؛ التطبيق يفشل
  مغلقاً حتى يُبنى.
- الأصول في `assets/` **نائبة مولَّدة** (`npm run assets:placeholders`).
- `npm install` و`expo prebuild` و`expo run:ios` تحتاج جهاز macOS مع Xcode.
